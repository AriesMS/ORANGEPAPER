# BASE REFERENCE LIBRARY

Use this as a starting point. You should also find at least one website/reference yourself and insert it into `DESIGN.md`.

## Editorial / Typographic
Look for oversized typography, asymmetric layouts, strong text/image hierarchy, deliberate whitespace, and readable grids.

Search terms:
- editorial portfolio website
- magazine inspired portfolio
- Swiss typography web design
- graphic designer editorial portfolio

Discovery:
- Awwwards - https://www.awwwards.com/
- SiteInspire - https://www.siteinspire.com/
- Minimal Gallery - https://minimal.gallery/

## Architecture / Minimal
Look for large project imagery, sparse navigation, project indexes, restrained typography, careful cropping, and generous margins.

Search terms:
- architecture studio website minimal
- architect portfolio project index
- architecture portfolio image-led

Discovery:
- Awwwards - https://www.awwwards.com/
- SiteInspire - https://www.siteinspire.com/
- Land-book - https://land-book.com/

## Technical / Research
Look for visible grids, metadata, project numbering, monospace accents, diagrams/data, and systematic hierarchy.

Search terms:
- computational design portfolio
- creative coding portfolio
- research lab website design
- data visualization portfolio

Discovery:
- Awwwards - https://www.awwwards.com/
- Godly - https://godly.website/
- SiteInspire - https://www.siteinspire.com/

## Experimental / Brutalist
Look for unconventional navigation, raw typography, exposed structure, unusual composition, and one strong interaction concept.

Search terms:
- brutalist portfolio website
- experimental web design portfolio
- unconventional navigation website
- creative developer portfolio

Discovery:
- Brutalist Websites - https://brutalistwebsites.com/
- Godly - https://godly.website/
- Awwwards - https://www.awwwards.com/

## When you find a reference you like
Put it in `DESIGN.md` and answer:
1. Why do I like it?
2. What specifically do I want my site to follow?
3. What do I **not** want to copy?
